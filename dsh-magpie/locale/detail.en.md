Manage Magpie models in DSH and sync them to the Magpie group in the model picker.

- Enter the gateway address in the connection tab and check the connection.
- Import or add models, select and reorder them, then save and sync.
- Use the update tab to download or update Magpie for Windows and check for plugin updates.

[Full documentation](https://github.com/zhiqiangme/dsh-plugins/tree/main/dsh-magpie#readme)
