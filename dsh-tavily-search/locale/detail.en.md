Use Tavily as the web search backend in DSH.

- Add a Tavily API key in the API Key tab. DSH stores it in its credential store.
- On DSH 0.2.2-rc.2, Tavily connects on first install in a profile using the default search configuration. If you already selected a provider, switch to Tavily from the web search tab.
- Run a test search in the search endpoint tab to verify that Tavily returns results.

[Full documentation](https://github.com/zhiqiangme/dsh-plugins/tree/main/dsh-tavily-search#readme)
