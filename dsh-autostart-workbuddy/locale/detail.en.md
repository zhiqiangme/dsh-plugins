> **This plugin is no longer maintained** (final release `26.11.24`) and will no longer track upstream or DSH changes. Please switch to the Magpie plugin `@zhiqiangme/dsh-magpie`. When removing this plugin, click “Fully uninstall” in the Backend tab first to clear backend data, then uninstall it on the Plugins page.

Start a WorkBuddy gateway and sync selected models to DSH.

- Choose wb2api (default, misakano7545 fork) or WorkBuddy2API Hub in the backend tab, where you can also install or update the gateway.
- For Hub, configure regions and credentials in the region and key tab.
- Select models in the models tab, turn on DSH model sync, then save and sync.

[Full documentation](https://github.com/zhiqiangme/dsh-plugins/tree/main/dsh-autostart-workbuddy#readme)
